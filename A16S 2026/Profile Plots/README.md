Script to generate comparison profiles between discrete and CTD oxygen data on GO-SHIP A16S cruise for QC purposes. This script was updated almost daily during this cruise and requires the .btl file for each cast (not uploaded on this repo). The script reads in the discrete oxygen data from a running QC file maintained by the analysts during the cruise. It also requires a station data file in order to loop everything correctly. Hopefully I will be able to come up with a less clunky solution in the future.
